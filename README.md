# Pacman — Fayda Tabanlı Rasyonel Ajan

Python ile geliştirilen, grafik arayüzlü bir Pacman oyunu ve oyunu bağımsız
olarak oynayan **fayda tabanlı rasyonel ajan** (utility-based rational agent).
İnsan oyuncu ve yapay zekâ aynı haritada, aynı kurallarla sırayla oynar; iki
turun sonunda kazanan ekranda gösterilir.

> Proje geliştirme aşamasındadır. Kurulum, kurallar ve ajan tasarımı bu
> belgede ilgili fazlar tamamlandıkça ayrıntılandırılacaktır.

## Kurulum

```bat
python -m venv .venv
.venv\Scripts\activate
python -m pip install -r requirements.txt
python main.py
```
